# UNO R4 WiFi 수동 버저 USB 연결

이 스케치를 업로드하고 시리얼 모니터를 115200 baud로 열어 C를 보내면 짧은 정답 소리, F는 긴 종료 소리, S는 중지를 실행합니다. Wi-Fi는 필요하지 않습니다. 이 명령은 PC 게임용 자체 프로토콜이며 허스키렌즈 프로토콜이 아닙니다.

2핀 수동 버저를 사용합니다. 버저 정격 전류가 UNO R4 GPIO 허용 범위 이내인 경우에만 +를 D8, −를 GND에 직접 연결하세요. 범위를 초과하거나 정격을 모르면 트랜지스터 구동 회로를 사용해야 합니다. 전원을 끄고 배선하세요.

Arduino IDE에서 Arduino UNO R4 Boards 패키지를 설치하고 보드 UNO R4 WiFi를 선택한 뒤 BuzzerBridge.ino를 검증·업로드하세요. 실제 하드웨어 컴파일, 업로드 및 소리 확인은 아직 수행하지 않았습니다.

일반 모니터에는 터치 감지 기능이 없으므로 이 스케치만으로 화면 접촉을 입력받을 수 없습니다. 게임의 화면 입력 방식과 허스키렌즈2 관절 데이터 연결은 별도로 확정해야 합니다. 기존 HandGame 스케치는 이전 물리 버튼 버전입니다. 두 스케치를 함께 업로드하지 마세요.
